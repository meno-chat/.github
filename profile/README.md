<h1 align="center">Meno</h1>

<p align="center"><b>An AI that <s>gives you answers</s> <i>actually</i> helps you learn.</b></p>

Meno is an open-weight tutoring model in development. It's being built to give hints and ask questions instead of handing over answers, and to be measured honestly on [TutorBench](https://arxiv.org/abs/2510.02663).

> **Status: in development. Nothing has been released yet.**

## Repositories

| Repo | What it is |
|---|---|
| [meno-8b](https://github.com/meno-chat/meno-8b) | Main project: goals, roadmap, evaluation rules, brand guidelines, and scripts |

## Principles
- **Hints before answers.** The goal is a model that helps students reason, not one that does the work for them.
- **Honest evaluation.** No training on benchmark test data, and every reported score comes with its method.
- **Open by default.** Code under Apache 2.0. Model weights will carry the license of their base model, stated in each model card.
